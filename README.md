# PARRY CUBE — 패리 큐브

검 하나, 총 하나를 든 네모가 몰려오는 적을 버티는 2D 뱀서라이크.
총은 알아서 쏘고, 나는 움직이면서 타이밍 맞춰 베어서 **패리**해요.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 빌드
```

## 조작

| 키 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동 |
| 스페이스 · 마우스 클릭 | 베기 / 패리 (마우스 방향, 마우스가 없으면 가장 위험한 쪽) |
| Shift | 대시 (무적) |
| R | 재장전 |
| Esc / P | 일시정지 |

모바일은 왼쪽 화면 드래그로 이동하고, 베기·대시 버튼을 써요.

## 핵심 규칙

- **총은 자동 사격, 히트스캔.** 탄이 날아가지 않고 쏘는 순간 바로 맞아요.
- **모든 적 공격은 패리할 수 있어요.** 근접 공격, 돌진, 내려찍기, 원거리 탄 전부요. 적 머리 위에 `!`가 뜨면 공격 신호예요.
  - 패리 판정 시간 안에 막으면 적이 기절하고 큰 피해를 입어요. 원거리 탄은 반사돼요.
  - 베기를 누르고 **0.075초 안**에 막으면 PERFECT: 더 긴 히트스톱, 슬로모션, 3배 피해.
  - 패리에 성공하면 검 쿨타임이 바로 초기화돼요 (반격).
- 몸통 박치기 피해는 없어요. 진짜 공격만 아파요.
- 4:00 감시자 큐브, 8:00 붉은 군주(최종 보스). 최종 보스를 쓰러뜨리면 승리.

## 상점

- 총 / 검 / 큐브 스킨(12종) 칸이 각각 4개씩 있어요.
- 등급별 입고 확률: 일반 52% · 고급 27% · 희귀 13% · 영웅 6% · 전설 2%.
- 재고는 등급이 높을수록 적고, 다 팔리면 **재고 없음**으로 표시돼요.
- 출격이 끝날 때마다, 그리고 15분마다 새로 입고돼요. 골드를 내고 새로고침할 수도 있어요.
- 이미 가진 무기를 또 사면 강화돼요 (+8% 피해, 최대 +5).
- 카드를 누르면 로비의 큐브가 그 무기나 스킨으로 직접 시연해요.

## 구조

```
src/engine   픽셀 렌더러(색 버퍼 + 가산 광원 버퍼, 디더링), 입력, 합성 효과음
src/game     무기/적/플레이어/월드, 이펙트, 데이터, 세이브·상점
src/ui       HUD, 로비/상점/장비/레벨업 화면
```

그래픽과 소리는 이미지·음원 파일 없이 전부 코드로 만들어요.
이펙트는 [pixelfx](https://github.com/patch-gg/pixelfx) 스킬의 방법론(예비동작 → 타격 프리즈 → 회복, 빛과 선 위주의 연출)을 참고해서 직접 작성했어요.
폰트는 [Galmuri](https://github.com/quiple/galmuri) (SIL OFL)를 써요.
