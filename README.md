# AXENFALL — 네모 용사의 대모험

옆으로 긴 네모 몸에 눈 두 개, 짧은 다리만 달린 주인공이 여러 능력을 바꿔 가며 싸우는 픽셀아트 횡스크롤 액션 게임입니다.
모든 그래픽(캐릭터, 몬스터, 배경, 타이틀 로고, UI)은 코드로 한 픽셀씩 생성됩니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 빌드
```

## 조작

| 키 | 동작 |
| --- | --- |
| ← → | 이동 |
| C / Space / ↑ | 점프 (2단 점프) |
| ↓ + 점프 | 발판에서 내려가기 |
| X | 평타 (연속 입력 시 콤보) |
| Z / Shift | 대시 (무적) |
| A · S · D | 스킬 1·2·3 |
| F | 궁극기 (게이지 100%, 피격 중에도 사용 가능) |
| ESC / P | 일시정지 |

## 현재 구성 (1단계)

- **능력 8종** — 등급 N / R / SR / SSR / UR, 각각 평타 콤보 + 스킬 2개 + 궁극기
  - 블레이드(N), 플레임(R), 프로스트(R), 볼트(SR), 게일(SR), 섀도우(SSR), 스타폴(SSR), 보이드(UR)
- **소환(뽑기)** — 1회 100 / 10회 1000 보석, 10회 시 에픽 이상 1개 확정, 50회 천장(레전드 이상)
  - 중복 획득 시 조각 → 별 승급, 골드로 레벨업
- **캐릭터** — 장착 능력(평타·몸 색) 선택, 보유한 모든 능력의 스킬을 섞어서 A/S/D/F 슬롯에 편성, 체력·공격력 강화
- **월드 1 「이끼베일 숲」** — 6 스테이지, 일반 몬스터 4종 + 정예, 중간 보스 3종, 최종 보스 「고목왕 엘더우드」
- **보상** — 클리어 별 3개(클리어 / HP 50% 이상 / 제한 시간), 골드·보석, 첫 클리어 보너스

## 사운드

효과음은 Kenney의 CC0 에셋입니다 (`public/audio/CREDITS.md`).
배경음은 `public/audio/bgm/`에 `.ogg`를 넣고 `bgm.json`에 등록하면 자동으로 재생됩니다
(`title`, `menu`, `stage`, `boss` 키).

## 구조

```
src/art      픽셀아트 생성기 (셰이딩 페인터, 주인공, 몬스터, 배경, 로고, 아이콘)
src/battle   전투 (플레이어, 히트박스, 투사체, 스킬/궁극기, 몬스터 AI, 보스)
src/data     능력·스킬·스테이지 데이터
src/scenes   타이틀 / 로비 / 월드 / 스테이지 선택 / 캐릭터 / 소환 / 전투 / HUD / 결과
src/core     세이브, 사운드, UI 위젯
```
