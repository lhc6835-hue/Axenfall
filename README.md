# PARRY CUBE — 패리 큐브

검 하나, 총 하나를 든 네모가 몰려오는 적을 버티는 2D 뱀서라이크.
총은 알아서 쏘고, 나는 움직이면서 타이밍 맞춰 베어서 **패리**해요.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 빌드
```

## 조작

| 키 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동 |
| 스페이스 · 마우스 클릭 | 베기 / 패리 (마우스 방향, 마우스가 없으면 가장 위험한 쪽) |
| Shift | 대시 (무적) |
| R | 재장전 |
| Esc / P | 일시정지 |

모바일은 왼쪽 화면 드래그로 이동하고, 베기·대시 버튼을 써요.

## 핵심 규칙

- **총은 자동 사격, 히트스캔.** 탄이 날아가지 않고 쏘는 순간 바로 맞아요.
- **모든 적 공격은 패리할 수 있어요.** 근접 공격, 돌진, 내려찍기, 원거리 탄 전부요. 적 머리 위에 `!`가 뜨면 공격 신호예요.
  - 패리 판정 시간 안에 막으면 적이 기절하고 큰 피해를 입어요. 원거리 탄은 쏜 적에게 그대로 되돌아가요.
  - 패리는 칼날이 실제로 지나간 방향에서만 일어난다. 칼이 그 방향을 지나가는 순간(0.05초 안)에 막으면 PERFECT: 더 긴 히트스톱, 슬로모션, 3배 피해.
  - 패리에 성공하면 검 쿨타임이 바로 초기화돼요 (반격).
- 몸통 박치기 피해는 없어요. 진짜 공격만 아파요.
- 4:00에 중간 보스, 8:00에 최종 보스가 나온다. 최종 보스를 쓰러뜨리면 승리.

## 월드

로비에서 월드를 고른다. 앞 월드를 클리어하면 다음 월드가 열린다.

| 월드 | 이름 | 중간 보스 | 최종 보스 |
| --- | --- | --- | --- |
| 1 | 자정 회랑 | 감시자 큐브 | 붉은 군주 |
| 2 | 용광로 심층 | 용광로 골렘 | 황혼 검객 |

월드 2는 적 체력 1.45배, 골드 1.7배. 쇳물이 흐르는 철판 바닥에 전용 배경음이 깔린다.

**월드 2 적**
- 창병: 바닥에 찌르기 선을 긋고 길게 찌른다. 사거리가 길다.
- 방패병: 정면에서 오는 총알을 85% 막는다. 옆이나 뒤에서 쏘거나 검으로 벤다. 방패 돌진도 한다.
- 저격수: 조준선으로 따라오다가 고정되는 순간 아주 빠른 탄을 쏜다.
- 박격수: 포탄을 던진다. 떨어질 자리에 원이 뜨고, 터지면 사방으로 탄이 퍼진다.
- 분열체: 죽으면 작고 빠른 파편 2~3개로 갈라진다.
- 톱날 투척병: 회전 톱날을 던진다. 톱날은 날아가며 느려지다가 부메랑처럼 던진 적에게 되돌아온다. 갈 때와 올 때 두 번 노린다. 패리하면 톱날이 적에게 날아간다.

**용광로 골렘**: 내려찍기 충격파(퍼지는 고리. 고리 쪽을 보고 베면 패리, 대시로 통과 가능), 앞쪽 넓게 휩쓰는 팔 공격, 쇳물 포탄 일제 사격.

**황혼 검객**: 순식간에 붙어 3연베기(체력 절반 이하 4연베기. 매 타마다 `!`가 뜨니 박자 맞춰 패리), 초승달 검기 3발, 가드 자세(총알을 튕겨 되쏜다. 검으로 베면 가드 브레이크), 체력 절반 이하에서 플레이어를 둘러싼 칼날 8자루 낙하.

## 상점

- 총(26종) / 검(24종) / 큐브 스킨(14종) 칸이 각각 6개씩 있어요.
- 등급별 입고 확률: 일반 51% · 고급 27% · 희귀 13% · 영웅 6% · 전설 2% · 신화 0.75% · 초월 0.25%.
- 재고는 등급이 높을수록 적고, 다 팔리면 **재고 없음**으로 표시돼요.
- 출격이 끝날 때마다, 그리고 15분마다 새로 입고돼요. 골드를 내고 새로고침할 수도 있어요.
- 이미 가진 무기를 또 사면 강화돼요 (+8% 피해, 최대 +5).
- 카드를 누르면 로비의 큐브가 그 무기나 스킨으로 직접 시연해요.

## 계정 · 클라우드 저장 (Cloudflare)

아이디/비밀번호로 가입하면 골드·무기·스킨·장비·기록·상점이 클라우드에 저장되고, 다른 기기에서 로그인해 이어서 할 수 있다.
효과음·배경음·전체화면 같은 기기 설정은 동기화하지 않는다.
**새로 가입하면 처음부터** 시작하고, **로그인하면 그 계정에 저장된 진행**으로 바뀐다. 이 기기에 진행이 쌓여 있으면 사라질 내용과 불러올 내용을 보여 주는 경고가 먼저 뜨고, 취소하면 아무것도 바뀌지 않는다.
로그인한 채로 두 기기에서 따로 플레이해 진행이 달라지면 어느 쪽을 남길지 고르는 창이 뜬다.

서버는 `functions/api/[[route]].ts`(Cloudflare Pages Functions)이고 데이터는 Cloudflare D1에 저장된다.
비밀번호는 PBKDF2(SHA-256, 100,000회)로 해시해 저장하고, 로그인 토큰도 해시로만 보관하며 30일 뒤 만료된다.
비밀번호를 5번 틀리면 1분간 잠긴다. 테이블은 첫 요청 때 자동으로 만들어진다.

### 현재 배포
- 계정 API: `https://parrycube-api.celesta.workers.dev` (Cloudflare Worker, `worker/`), D1 데이터베이스 `parrycube`.
- 게임(GitHub Pages)은 `src/net/cloud.ts`의 `CLOUD_API`로 이 주소를 부른다.
- 다시 배포: `cd worker && npx wrangler deploy`

### 연결 방법 (Pages로 직접 올릴 때)
1. Cloudflare 대시보드 → **Workers & Pages** → **Create** → **Pages** → **Connect to Git** → 이 저장소 선택
   - Production branch: `ccr-dd5f27cd-agud00` · Build command: `npm run build` · Build output directory: `dist`
2. **Storage & Databases → D1** → **Create database** (이름 예: `parrycube`)
3. 만든 Pages 프로젝트 → **Settings → Bindings → Add → D1 database**
   - Variable name: `DB` · Database: 2번에서 만든 데이터베이스 → 저장 후 **재배포**
4. `https://<프로젝트>.pages.dev`로 접속하면 로비 오른쪽 위에 **로그인** 버튼이 나온다.

GitHub Pages 쪽(`github.io`)에서도 계정을 쓰려면 `src/net/cloud.ts`의 `CLOUD_API`에 Pages 주소를 넣는다.
다른 주소에서 API를 부르려면 Pages 환경 변수 `ALLOWED_ORIGINS`에 쉼표로 구분해 넣는다.

### 로컬에서 시험
```bash
npm run build
npx wrangler pages dev dist --d1 DB=local-parrycube --port 8788   # API + 로컬 D1
npm run dev                                                        # /api 요청은 8788로 프록시
```
